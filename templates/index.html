HOW IT WORKS

Simple data-mining pipeline

01
Clean and label

Remove empty messages and map labels into spam / legitimate classes.

02
TF-IDF features

Convert words and short phrases into numeric features.

03
Train Naive Bayes

Fit a lightweight text classifier on labeled examples.

04
Evaluate, then refit

Measure a held-out split, then train the active model using the full uploaded dataset.

◇

Privacy by design
Uploaded training rows are processed locally and are not saved as a raw dataset by this app. Only the trained model and evaluation summary are stored under instance/.

↗
SIH CONTEXT

What this prototype covers — and what it does not

This is an educational spam/phishing-text classifier related to the email-detection part of SIH 2026 PS SIH26106. It does not yet verify SPF/DKIM/DMARC, parse raw email headers, query domain/IP reputation, geolocate senders, correlate campaigns, or create evidentiary forensic reports. Do not describe those features as implemented.
